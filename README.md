# MSCS532 Assignment 3: Understanding Algorithm Efficiency and Scalability

## Overview

This project implements and analyzes two important algorithmic concepts:

1. Randomized Quicksort
2. Hash Table with Chaining

The project includes theoretical analysis and empirical testing to examine algorithm efficiency and scalability.

## Files

- `randomized_quicksort.py` - Implements Randomized Quicksort using a randomly selected pivot.
- `deterministic_quicksort.py` - Implements deterministic Quicksort using the first element as the pivot.
- `benchmark.py` - Compares the execution time of randomized and deterministic Quicksort.
- `hash_table.py` - Implements a hash table using chaining, universal-style hashing, load-factor tracking, and dynamic resizing.

## Running the Programs

Make sure Python 3 is installed.

### Run Randomized Quicksort

```bash
python randomized_quicksort.py
